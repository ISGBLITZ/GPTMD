This file is for the directions to run the streamlit app.
You must install Python version 3.11.9.
First, you must go to Azure and find Microsoft Foundry. Click on it and create it.
Second, you must create an agent using the gpt of your choice in Foundry. Make up a name you can remember.
Third, you must clone this repository into a file structure in your computer.
Fourth, go to .env and change the environment variables for each variable. Do not use quotation marks.
Finally, run the batch file known as iwanthealth_venv.bat.
